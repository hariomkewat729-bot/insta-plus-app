# 📸 Insta Plus - Instagram जैसा Photo & Video Sharing App

**Insta Plus** एक आधुनिक, उपयोग में आसान photo और video sharing application है जो Instagram की तरह काम करता है।

## ✨ मुख्य फीचर्स

✅ **यूजर रजिस्ट्रेशन और लॉगिन**
- सुरक्षित साइन अप और लॉगिन
- Email और Password सुरक्षा
- Profile Customization

✅ **फोटो शेयरिंग**
- आसान फोटो अपलोड
- कैप्शन और hashtags
- Real-time फीड

✅ **Social Features**
- 👍 Like और Unlike
- 💬 Comment करना
- 👥 Follow/Unfollow
- 🔍 यूजर और पोस्ट खोजना

✅ **यूजर प्रोफाइल**
- Profile Picture
- Bio
- Followers Count
- Posts Count
- Following List

✅ **खूबसूरत UI**
- Responsive Design
- Instagram जैसा Interface
- Smooth Animations
- Dark & Light Support

## 🚀 शुरुआत करें

### Requirements
- Node.js (v14 या ऊपर)
- npm या yarn

### Installation

```bash
# Repository clone करें
git clone https://github.com/hariomkewat729-bot/insta-plus-app.git

# Directory में जाएं
cd insta-plus-app

# Dependencies install करें
npm install

# Development server चलाएं
npm start
```

एप्लिकेशन `http://localhost:3000` पर खुल जाएगा।

## 🎯 कैसे उपयोग करें

### 1. Account बनाएं
- **रजिस्टर पेज** पर जाएं
- यूजरनेम, Email, और पासवर्ड भरें
- "रजिस्टर करें" बटन दबाएं

### 2. लॉगिन करें
- Email और पासवर्ड दर्ज करें
- "लॉगिन करें" पर क्लिक करें

### 3. फोटो पोस्ट करें
- "अपलोड करें" मेन्यू पर क्लिक करें
- एक तस्वीर चुनें
- कैप्शन लिखें
- "पोस्ट करें" बटन दबाएं

### 4. फीड ब्राउज़ करें
- होम पेज पर सभी पोस्ट देखें
- Like, Comment, और Share करें
- यूजर को Follow करें

### 5. प्रोफाइल देखें
- किसी भी यूजर के प्रोफाइल पर जाएं
- उनकी सभी पोस्ट देखें
- Follow/Unfollow करें
